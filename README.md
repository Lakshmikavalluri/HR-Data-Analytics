# HR Data Analytics

An end-to-end HR analytics project that uses **SQL**, **Power BI**, and **Tableau** to analyze workforce data and uncover insights on headcount, attrition, and employee performance.

---

## Project Objective

Help HR and business leaders answer questions such as:

- How many employees do we have, and how is headcount changing over time?
- What is the overall attrition rate, and which departments or roles are most affected?
- How do salary, tenure, age, and gender distribution vary across the company?
- What factors are linked to employees leaving?

## Approach

1. **Data Cleaning (SQL):** Checked for duplicates and null values, standardized columns, and created calculated fields such as age groups and tenure bands.
2. **Analysis (SQL):** Wrote queries to calculate headcount, attrition rate, average salary, and satisfaction by department.
3. **Visualization (Power BI and Tableau):** Built dashboards with KPI cards, charts, and filters for easy exploration.
4. **Insights:** Summarized the main findings for decision-makers.
